# منصة تواصل اجتماعي عربية (RTL)

## ملاحظتان تقنيتان قبل البدء
- التنقل في هذا المشروع يعمل بـ TanStack Router (مثبّت في القالب) وليس React Router — نفس النتيجة، صفحات وروابط عادية.
- الباك إند: Lovable Cloud (قاعدة بيانات + مصادقة + تخزين + Realtime + RLS) — بدون أي حسابات خارجية.

## المرحلة 1 — الأساس (سأنفذها أولًا)
1. **نظام التصميم + RTL**: `dir="rtl"`، خط Tajawal، لوحة ألوان أزرق أساسي + أخضر/أحمر للتفاعلات، وضع ليلي، توكنات في `styles.css`.
2. **قاعدة البيانات**: كل الجداول المطلوبة (profiles, follows, posts, post_likes, comments, comment_likes, shares, stories, story_views, reels, reel_likes, reel_comments, conversations, conversation_participants, messages, notifications, blocks, reports, hashtags, post_hashtags) + جدول `user_roles` منفصل للأدمن.
   - RLS على كل جدول، مع دوال SECURITY DEFINER: `has_role`, `is_blocked`, `can_view_profile` (تحترم is_private و blocks).
   - Triggers: إنشاء profile تلقائيًا عند التسجيل، تحديث العدادات (likes/comments/followers/posts)، إنشاء الإشعارات، `expires_at` للستوريز.
   - Storage buckets: avatars, covers, posts-media, stories-media, reels-media (عامة) + messages-media (خاصة بأعضاء المحادثة).
3. **الأنواع (TypeScript)** لكل الجداول + هيكلة المجلدات `/components /routes /hooks /lib /types /features`.

## المرحلة 2 — الأساسيات
- تسجيل/دخول بالبريد + اختيار username فريد، حماية الصفحات.
- البروفايل: غلاف، صورة، نبذة، عدادات، تبويبات (بوستات/ريلز/وسائط/إعجابات)، تعديل البروفايل والخصوصية.
- الفيد: إنشاء بوست (نص/صور متعددة/فيديو + مستوى خصوصية)، استخراج الهاشتاجات، لايك/كومنت بردود متداخلة/مشاركة، تعديل وحذف بوستاتي، Infinite scroll.
- الشِل: Navbar للديسكتوب + Bottom navigation للموبايل، Skeletons، Toasts، Empty states.

## المرحلة 3 — الميزات المتقدمة
- **ستوريز**: شريط علوي بحلقات ملوّنة، عارض full-screen بتقدم تلقائي، اختفاء بعد 24 ساعة، قائمة المشاهدين لصاحب الستوري، الرد يفتح شات.
- **ريلز**: تمرير عمودي بملء الشاشة، autoplay عند الظهور، أزرار جانبية، رفع ريل، عداد مشاهدات.
- **الشات**: محادثات فردية وجماعية، Realtime للرسائل، مؤشر الكتابة عبر Presence، علامات القراءة، عدادات غير مقروء.
- **المتابعة والبحث**: متابعة/طلب متابعة للحسابات الخاصة، بحث مستخدمين وهاشتاجات، اقتراحات، قوائم المتابِعين/المتابَعين.
- **الإشعارات اللحظية**: جرس بعداد، قائمة منسدلة، صفحة كاملة (الكل/غير مقروء).

## المرحلة 4 — الإعدادات والأدمن
- تغيير كلمة المرور، الخصوصية، الحظر، من يعلّق على بوستاتي، البلاغات، حذف الحساب.
- لوحة أدمن: إحصائيات، مراجعة البلاغات واتخاذ إجراء، إدارة المستخدمين (عبر دور admin في `user_roles`).

## الحجم
مشروع كبير؛ سأسلّمه على المراحل أعلاه بالترتيب وأخبرك بعد كل مرحلة لتجربتها.
